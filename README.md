# Mythic Katana Mod

The Mythic Katana Mod is a unique Minecraft mod that introduces a custom dual-element mythic katana sword with high contrast blade visuals. One half of the blade is glowing neon sapphire blue energy, and the other half transitions into burning crimson red fire aura. The sword features low-poly, smart-topology, voxel art with a pixelated retro gaming texture. It grants the holder permanent Speed II while held in the main hand and has a special "Furia" mode that activates after killing 4 players or mobs, granting Strength III for 30 seconds.

## Install

1. Download the Mythic Katana Mod JAR file from the GitHub repository.
2. Place the JAR file in the `mods` folder of your Minecraft installation directory.
3. Launch Minecraft with the Fabric mod loader installed.

## Use

1. Craft the Mythic Katana using the provided recipe.
2. Hold the sword in your main hand to gain permanent Speed II.
3. Kill 4 players or mobs to activate "Furia" mode, which grants Strength III for 30 seconds.
4. The sword can only be crafted or obtained once per world/server. To get a second one, defeat the Warden or Wither with a 1 in 1,000,000 drop chance.
